Detailed Description

template<typename ValueType_>
class tracking::math::Rotation2D< ValueType_ >

Constant 2D rotation by a fixed angle theta, caching cos/sin.

Shared rotation helper for SE(2) transforms used by observation::SensorMountingPose and env::EgoMotion, so the rotation algebra has a single source of truth.

ValueType_The atomic floating-point type of internal elements
