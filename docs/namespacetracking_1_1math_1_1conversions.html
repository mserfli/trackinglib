Creates a CovarianceMatrixFactored from a nested initializer list.

This function constructs a factored covariance matrix by decomposing the input covariance matrix into UDU^T form. The input must be symmetric.

Template Parameters
ValueType_The atomic data type of internal elements
Size_The dimension of the covariance matrix
Parameters
[in]listNested initializer list representing the full covariance matrix
Returns
tl::expected containing the factored covariance or a propagated dimension, symmetry, or decomposition error
Note
Checks dimensions and symmetry before decomposition. The existing UDU algorithm clamps non-positive pivots to epsilon; it does not enforce strict positive definiteness of the input. For example, diag(-1, 1) succeeds here with the first pivot clamped, while full-policy model creation rejects it.
No comprehensive NaN/Inf check is provided. noexcept describes exception behavior and does not guarantee successful construction or finite numbers.
See also
CovarianceMatrixFactored::FromList for explicit U/D input without clamping
