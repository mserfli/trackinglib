Detailed Description

template<typename CovarianceMatrixPolicy_, typename StateDef_>
class tracking::observation::TEST_REMOVE_FINAL< CovarianceMatrixPolicy_, StateDef_ >

Observation model for a polar bearing-only measurement.

Observation model for a direct velocity measurement (vx, vy).

Observation model for a polar range-only measurement.

Observation model for a polar range/bearing measurement.

Observation model for a polar range/bearing/doppler measurement (e.g. radar).

Observation model for a direct position measurement (x, y).

Nonlinear observation model measuring the bearing of the position: h(x) = atan2(y, x)

The bearing innovation is wrapped into [-pi, pi] by the shadowed computeInnovation().

Note
Measurements z and predictions h(x) are expressed in the sensor frame defined by the mounting pose (see ExtendedObservationModel::getSensorPose()); an identity pose makes the sensor frame coincide with the tracking frame.
Template Parameters
CovarianceMatrixPolicy_Policy type that defines the covariance matrix implementation
StateDef_State definition structure of the observed motion model (requires X and Y)
